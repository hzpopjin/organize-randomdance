# 随舞主办

面向第一次举办活动的主办者，也适用于已有活动的单项工作。把策划、剪歌、歌单导出、路演、海报和现场管理整理成有输入、行动、产物和验收条件的八阶段路线。

## 从哪里开始

让支持技能的AI助手读取 [SKILL.md](SKILL.md)，或直接从 [新人路线图](references/beginner-roadmap.md) 开始。告诉它当前活动形式、时间地点是否确定、已有资源与本次想完成什么。无需一次填完全部模板。

1. 定范围与主办能力
2. 场地档期与书面合作
3. 人员、设备与安全方案
4. 征集与宣传
5. 剪歌与节目编排
6. 成品验收与交接
7. 彩排与现场执行
8. 撤场与复盘

技能内部编号为0–7。纯随舞默认整场；带路演采用独立分支。场地、真实音源、人员或安全条件不足时，保留明确阻塞和下一步，不把草案当成已完成活动。

## 安装与使用

下载ZIP后解压，保留整个 `organize-randomdance` 文件夹及相对目录。按所使用AI工具的技能安装方式添加该文件夹；安装入口因工具而异，不需要运行安装脚本。本包没有自动执行脚本，也不包含音频主程序。

不支持技能安装的工具也可以阅读入口和引用资料。示例请求：

- “使用随舞主办技能，带我从零筹备一场纯随舞，先确认当前最重要的缺项。”
- “按指定歌单保留重复条目，检查Custom素材和节目时长，给我可执行的下一步。”
- “这场有路演，帮我检查成员兼组、换装和候场冲突。”

模板在 [assets/templates](assets/templates)，按需复制使用；CSV可转换成Excel，转换和音频工具能力应先检查。没有真实音源或可运行工具时，不会仅凭清单就得到可播放MP3。

## 覆盖范围

- 商场尽量提前3–4周定档，收费方向与书面合作细节核对
- 普通副歌及Custom的版本定位、连续剪辑、上退场、命名与质量检查
- 随机歌单编排、音源预检、同步MP3/CSV/SRT与Excel/PDF流程
- 路演报名、成员与兼组排期、彩排和现场交接
- 封面、歌单、路演海报与公开资料检查
- 撤场、验收结算待办和复盘

## 测试与边界

新人路线已做独立桌面模拟：八阶段规划、九类异常处理；输入转换缺口发现后已补充并复测。模拟不等于真实音频生产或现场验收。实际执行仍需要合法可用音源、合适工具、现场人员设备、场地方确认和当地适用要求。

本包不附歌曲、原始合同、真实名单、私人路径或来源附件工作簿；公开版文字模板为重新编写的精简表单，保留功能性CSV字段。它不是自动办活动的软件，也不保证线下成功。
