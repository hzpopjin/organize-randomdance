# 活动范围与筹备

先填活动简报，确认主办决策人、城市/时区、目标参与者、预算及可投入人手。分清纯随舞与带路演；没有实际节目时不虚构节目数量。预算把已确认资金、估算支出和未确定赞助分开。

商场档期尽量提前3–4周确认，具体审批、进场/试音/彩排/活动/撤场窗口按本场书面约定。收费合作先确认付款方向，详细核对见 [商场协作](mall-coordination.md)。场地意向不等于活动定档或审批通过。

任务按依赖推进：范围 → 场地与合作 → 人员设备 → 征集 → 内容制作 → 成品与团队确认 → 彩排 → 执行 → 交接复盘。可以并行起草，但不能跳过关键验收。

总控、播放、主持、催场/秩序各有人负责；小团队兼岗要检查同时发生的任务，不能让播放员离台催场。场地方协作须确认，不把期待当作人手。

活动预算占用分别计算开场、实际随舞音频、路演音乐及介绍/上下场、休息、结束与机动；布置彩排和撤场另列。成品已含倒数或间隔不再重复计时。

缺钱、场地或人手时给缩小规模、减少时长、找协作方或改期的选项，由用户决定。不要自行收费、采购或对外承诺。
