# 活动歌单与参与流程

## 征歌与公开展示

新征集先确认音乐范围、截止、数量限制、版本/段落请求与来源，说明提交不保证入选。保留每条投稿来源，歌曲、片段、播放条目各有稳定映射。同一版本同一段落的候选请求可以汇总，但正式指定sheet的重复播放条目不得擅自删除；全曲/副歌/不同Custom请求不能自行选择其一覆盖。

保留韩文、括号副标题和内部连字符；不能按任意短横线拆歌手。完整独立括号行可在明确归属时视为上一曲副标题，含糊时确认。长名折行不是新增歌曲。公开数量先区分独立曲数和播放片段数；同歌不同团队是不同路演节目。

既有常规流程用预先固定的受约束随机顺序、seed和同团不相邻检查，不按热度擅自干预。若用户另外指定策划顺序或现场实时抽播，明确区别：策划调整不叫完全随机；现场抽播需核验全部候选音频、重复政策、已播记录、总时长和固定备用稿。公开曲目池、公开真实顺序与接受临时点歌分别确认。

## 总时长

完整活动 = 开场 + 实测随舞成品 + 路演占用 + 独立休息/主持 + 收尾 + 明确机动。已包含的倒计时/空白/转场不重复计；节目汇总与逐节目子项只计一种。没有实测时标估计，未知不当零。

常规整场继续默认不分场。只有用户明确安排多轮/路演/休息时规划这些模块，不能用两小时示例倒推虚构曲目，也不自动把102分钟音频拆半。整场音频已经有时间线时，现场表引用成品时长和恢复时间码，不再次逐条播放源片段。

## 参与及转换

自由随舞自愿入圈和退出，明确入口/退场、通道、饮水休息；不要强迫不会跳的人进入中央。主持提示放合适边界，避免盖住音乐数拍。进入路演前清空节目区，全员/道具就位，总控确认后发音乐口令；结束确认退场和地面后恢复随舞。

临时点歌先记备选，不自动打断定稿。迟到跳过或提前下一组都需复核兼组准备时间。出现拥挤、危险地面或不适先由现场负责人暂停并按场地方案处理；助手不凭模板宣称场地安全、人员就绪或设备已试音。

## 宣传与更正

按任务起草预告、征集、正式信息、行前提醒或回顾，不自动发送/发布。关键日期地点参加方式待定时仍为草稿。更改时间检查封面、页脚、文案、入口和执行表；改变节目同步公开序号、主持、候场、音频映射，保留稳定ID与变更记录。回顾区分直接观察、主办判断与参与者意见，不把某段无人入圈直接当不受欢迎。
