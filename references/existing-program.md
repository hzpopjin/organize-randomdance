# 既有 Windows 程序接口与证据

## 证据范围

接口依据用户提供的既有流程说明整理；本技能不包含该主程序源码或历史活动数据。执行时先检查当前源文件、--help、依赖及真实输入，不把流程说明当成本次已运行或已验收证据。

没有既有程序时读 [新活动输入转换](new-activity-input.md)，先形成九列Excel与媒体清单，再用可用工具和短样本测试建立本次流程；不要将本节CLI当作已经安装的能力。

## 配置当前环境

用当次已确认的位置替换：<Python解释器>、<音频主程序.py>、<FFmpeg目录>、<全曲根目录>、<副歌根目录>、<Custom根目录>、<倒计时根目录>、<工作目录>及<活动输出目录>。不要保存真实用户名、盘符路径或上次活动文件名为默认值。

依赖为pydub、openpyxl与FFmpeg；能读取表格的解释器未必包含音频依赖。先检查现有能力，安装或改程序遵循当次授权。

## 文本报告的 CLI

--input 排序完成的Excel；--sheet 指定歌单sheet（历史默认“常规歌单”）；--output MP3完整输出路径（决定同名CSV/SRT）；--full-root、--chorus-root、--custom-root、--countdown-root 对应根目录；--summary-path 可选工作目录JSON；--split-threshold-seconds 默认0整场。

不提供随机 seed、团体映射、全曲间距 CLI；这些属于调用前的排序阶段。程序按表顺序合并，不负责随机。摘要默认不生成，需要才显式给 --summary-path。移动内部排序表后同步显式输入参数，不依赖旧默认值。

## 已报告修复与执行检查

旧活动曾修复：副歌／Custom错误检查全曲路径；跳过缺失音源仍导出；分块MP3再转码；长音频内存占用；系统临时目录无权限；Windows控制台无法输出部分字符。执行前检查当前版本是否仍保有正确行为，不假设历史修复一定在当前文件中。

用UTF-8控制台与utf-8-sig CSV，不能删去歌名字符解决编码问题。临时目录需实际可写。程序变更先按当前请求和授权保留备份；历史备份不表示当前可随意改代码。

## 未验证分支

流程文本的该场无全曲，因此有全曲开场／间距、各半场全曲开场、任意多场自动规划均未实际验证。现有自动二分不能满足这些规则，须在输入编排阶段完成并验收。SRT全播放器兼容性也未验证。不要将历史场次的seed、曲目数、页数、时差、相关性数值或行号当未来模板常量。
