# 数据关联与文件选择

公开版提供空白CSV与文字模板，不附原始附件工作簿。已有Excel可继续使用；新建工作簿时从CSV字段生成，按实际任务核对格式、公式和导出，不平行维护两套主数据。

## 三条数据链

1. 投稿请求 → 确认歌曲版本 → 具体播放条目 → 音频文件。歌曲、片段和播放条目不是同一对象；重复投稿可汇总来源，正式播放行保留次数。新表到音频程序输入按 [转换指南](new-activity-input.md) 操作。
2. 路演报名 → 一人一节目的成员记录 → 节目编排。节目ID与成员ID稳定，公开组序可以改变。同名昵称不能直接视为同一人，应向负责人核对。
3. 片段/节目 → 总流程 → 实际时间和变更。整轮成品按实测时长计一次，不能又加总源片段；节目汇总和子项也不能重复累加。

## 状态与时间

投稿收录与正式选用分开；节目审核、材料就绪、正式/候补、编排、人员到场分别记录。空值是未知，不是通过。核验人和时间必须来自实际检查。

现场表统一时区与时间格式，计划和实际分列。管理时长可用秒，音频输出仍采用内部毫秒时间线。兼组准备字段指该成员上一节目退场到下一节目候场所需时间，不用音乐开始差值替代。

音频文件名继续原basename或Custom中文备注，不因稳定ID改名。九列输入CSV需转为程序真实支持的Excel，不能宣称CSV就能被旧程序直接读取。

## 公开与交付

按字段白名单生成公开文件，不靠隐藏列保密。电话、内部评语、人员准备约束、未经许可的昵称与未成年人资料不公开；检查批注、隐藏行、链接及旧内容。

整场五文件布局不变：活动目录Excel/PDF，“随舞歌单”目录MP3/SRT/CSV。策划、海报、路演资料另外按任务交付，内部日志另存。各文件标活动和版本，同版交接；原件不覆盖，旧版处理需相应授权。

模板入口见 [模板索引](template-index.md)。
