# 商场对接与书面合同

## 定档与协作

按用户最新要求，商场活动尽量提前 **3–4周** 确认档期，替代旧的1–2周建议；这是筹备偏好，不是统一法律时限。临近活动尚未确认时标出风险，不能将初步意向写成已定场。

先确认本场双方主体及有权确认档期/合同的接口，区分意向、暂留、已书面确认；记录具体场地范围、日期、进场布置/试音彩排/活动/停止音乐/撤场时间。与商场确认审批流程、需提交的方案及安全预案、审核人和截止日期；旧范本“提前4个工作日提交”不是默认承诺。

筹备流程：3–4周前确认档期和范围 → 确认付费方向及书面合作细节 → 提交并核实商场方案意见 → 锁定宣传与设备/人员计划 → 行前复核和彩排 → 执行/撤场验收 → 按约交付结算。不能只因口头同意就标审批通过，或为赶进度自动公开未确认活动。

## 收费与书面约定

涉及收费时，按用户要求与商场以书面合同约定具体细节。先问清是商场向主办支付服务费、主办支付场租，还是互换/赞助等混合安排，不按甲乙称谓或旧合同猜付款方向。

使用 [商场对接](../assets/templates/mall-coordination.md) 与 [书面合同检查](../assets/templates/cooperation-contract-checklist.md)，至少核实：

- 当事主体、签署权限、活动范围、时间地点及双方接口。
- 主办服务清单：招募、路演、随舞、宣传、摄影或其他明确项目；场地方提供场地、电源、灯光、音响、围栏、保安、保洁等分别列责任与费用，不推定免费或全由一方承担。
- 费用金额/币种/含税口径、付款人与收款人、预付款/尾款节点和触发条件、发票类型及实际可开税率、必要凭证。银行账号等只在当次获准文件处理，不进入通用技能或公开资料。
- 客观交付与验收：节目/时长/人员/物料/素材、提交时间、验收人、反馈/整改流程。人数承诺须定义统计口径及现实依据；没有依据不承诺保底客流、传播或消费效果。
- 调整方案、额外工作/费用的书面确认；付款逾期、取消、改期、天气/场地故障、已发生可证明成本、预付款退还与结算办法逐项协商。旧范本固定比例、天数或扣款权不能自动照搬。
- 安全秩序与应急接口、暂停/恢复/取消的决定和通知流程，实际应由谁提供设备、维护场地与疏导客流；不要把片面免责或无限责任当成合理默认。
- 素材、音乐、编舞、肖像、Logo的使用来源与授权范围；不能因为主办组织活动就声明全部音乐/编舞归主办，也不能自动授予商场无限商业使用所有参与者影像。明确使用目的、媒介、期限、审核及相关同意。
- 生效与签署、补充协议/附件版本、未尽事项及争议解决等条款由双方确认；重大责任、知识产权或退款争议需用户或合适专业人士审阅。

## 权限与参考边界

本节是商务检查清单，不提供法律效力、税务适用或强制义务结论。引用具体法律、许可、税率等现行规则时须另查官方来源；历史协议不是法律依据。

只提取用户参考文档的流程，不保存范本企业名、地址、联系人、账号、签名或印章。原件不作为空合同模板直接附入技能。此处“签订合同”是业务完成节点，不授权助手代签、接受协议、付款或主动联系商场；实际行动遵循当次确认要求。草拟文件不等于发送或生效，签署状态只能依据实际证据更新。
