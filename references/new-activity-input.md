# 新活动从空表到音频输入

没有旧活动表或私人程序时也可开始。先用投稿/播放模板收齐数据，再做明确字段转换；不要让新人找别人的旧路径，也不要将空白CSV直接交给只接受Excel的程序。

## 最小转换

来源若为“歌曲投稿”，它只是请求池，先经主办选用并建立每次播放条目；不能按歌曲ID去重已选条目。来源若为“随舞播放”，保留所有正式选用的播放行和重复次数。每行用稳定ID/源行追踪，先解析实际模式及文件再排序。

创建独立内部Excel，sheet明确命名，前九列必须如下。可先复制 [九列输入空表](../assets/templates/playlist-engine-input.csv)，按表格技能转成.xlsx；这份CSV本身不是已支持的主程序输入。

| 目标列 | 标题 | 从何处来与检查 |
| --- | --- | --- |
| A | 序号 | 本次最终播放顺序1起；另在J保存原始行/ID |
| B | 歌手／组合 | 来源歌手字段，保留显示原文；团体比较另做映射 |
| C | 歌曲名 | 来源歌名，不因空格/括号截断 |
| D | 次要名称 | 已确认别名/副标题，无则留空 |
| E | 歌曲全称 | 原有完整显示名优先；否则用已核对的“歌手 - 歌名”，必要版本另明确，不编造别名 |
| F | 全曲／副歌／Custom | 由本次明确选择填写三种之一；“请求段落”含Intro/DB不自动覆盖明确模式，模糊则待确认 |
| G | 自由备注 | 保留请求与重要说明，不当程序命令 |
| H | filename | 全曲模式为实际原曲文件名；副歌模式为原basename对应文件名（程序改扩展名.mp3）；Custom可保留原曲映射，不要求该原曲存在 |
| I | CustomFilename | Custom模式的实际片段精确文件名；找到现有成果后填写，不猜后缀；非Custom可空 |

以下是映射说明，**全部模拟，不是真实歌曲或待播放数据**：

- 播放行C001：歌手“模拟组合A”、歌曲“曲目A”、明确模式副歌、实际文件“曲目A.mp3”。转换A=1、B=模拟组合A、C=曲目A、D空、E=模拟组合A - 曲目A、F=副歌、G=原备注、H=曲目A.mp3、I空。
- 播放行C002：歌曲“曲目B”、明确模式Custom、已核实实际文件“曲目B_第二副歌加舞蹈段.mp3”。F=Custom、I填该文件全名，H保留原文件映射。仅有请求但找不到实际片段时，不制作伪文件，标阻塞。
- 同一C001在列表中安排两次，生成两行不同A，J保留不同来源播放行；不要因歌曲/片段ID相同合并。

转换后检查条目身份与数量、F模式数量、文件名/备注逐条对应、E显示名，再按实际根目录预检。通过后才将这个.xlsx和sheet参数交给已验证的程序。

## 没有现成脚本怎么办

1. 助手先检查当前获准执行环境可用的表格工具、音频工具（例如FFmpeg/ffprobe）及目标输出要求。用户电脑工作按环境委派流程；读取能力检查不代表获准安装软件或改设备。
2. 有程序：查看实际接口是否支持九列契约；不要猜命令行。没有程序但工具可用：按“时间线导出”参考的契约制作本次工作脚本/处理流程，先用显著标模拟的短音频核对“倒计时+歌曲”、CSV/SRT和数量，测试通过后再处理真实已授权文件。脚本只放本次工作目录，不虚称技能已带自动主程序。
3. 音频工具不可用：仍交付已核对的九列输入、实际媒体清单、缺失项和输出参数；明确“尚未导出音频”，给用户具体下一步（提供音源/选择可运行环境/授权必要安装），不将制作步骤视为完成。
4. 没有Excel原生导出环境时，按已有打印规则说明限制和可选路径，不能把别的PDF生成器说成Excel原生导出。无法验证目标播放器也保留兼容性待确认。

**恢复点**：补齐文件回到音源预检；补齐工具回到短样本测试；修复映射只重验受影响条目。实际导出仍共用唯一毫秒时间线、一次最终MP3编码和五文件交付规则。
