# 彩排与现场管理

## 用户常用顺序

有路演的常规混合活动通常按：**彩排 → 上半场路演 → 上半场随舞 → 中场路演 → 随舞下半场 → 结束**。先采用此结构，再按当次实际时间、节目数量及场地窗口填具体时刻，不照搬参考活动的旧日期、时段或地址。

这条偏好用于混合活动总流程，不覆盖“无路演、只导出常规歌单时默认整场”。本场是否存在这些模块先核实；若要据此制作两段随舞音频，明确各段范围并生成独立时间线，不能仅因整场时长超一小时自动二分。

路演组一般安排提前 **60–30分钟到场报到和彩排**。发出具体通知前确认相对哪个正式开始时点、该组报到/彩排/候场/演出时刻，按人数与彩排容量细排；不要把“提前半小时”当作保证任何团队都够用。分批或中场组特殊到场约束单独确认，彩排结束到正式候场还须满足换装及兼组准备时间。

给每组提供节目ID、报到点、报到截止、彩排时段、最终音频版本、候场点/时间、进退场方向、负责人及变更渠道。准备提醒文案不等于已通知或已设提醒；发送或自动提醒须用户授权。

## 彩排验收

按 [彩排与现场模板](../assets/templates/rehearsal-site-plan.md) 记录实际检查：

- 全员/替补和道具是否到位，团队确认最终音频、动作开始/收尾、重播方式；负责人到场不等于全员就绪。
- 对照成品播放首尾、必要衔接与停止/恢复点，检查播放器离线文件、音量、主持麦克风、转接与备机；技术解码不等于现场试音。
- 走入场、定位、关键换位、道具摆撤与退场，统一表演者或观众视角；用实际舞区和地面验证，不能按图片推断安全。
- 与商场核实电源负载/接入、线路保护、音响朝向和允许音量、灯光控制/负责人及特殊效果限制；未经许可不改场地电路或灯光设置。
- 主持/播放/催场复述开始、暂停、结束和下一环节口令，确认唯一总控。问题写负责人和复核状态，未通过不勾“完成”。

## 分区、个人物品与观众秩序

绘制并与商场确认舞区、观众区、候场、报到、休息、更衣/化妆、饮水/垃圾、物品放置、摄影及播放台。路线、楼层和拍摄位置按当场核实，不沿用参考活动地点。

旧参考曾写消防通道存物，**不能复用该做法**。物品只放商场确认且不占堵疏散通道/消防设施的区域；保持出入口和商户经营动线。贵重物品建议随身、如无保管服务写明，不以“有监控”保证安全，不擅自搬走或丢弃他人物品。

候场与公开休息分别安排，不擅用商户付费座位或营业桌面。更衣/化妆在获准且适当的空间，不暴露于公区或占通道。熟食/外卖、饮品、座椅和席地休息等限制按本场与商场确认，不把旧活动禁令写成所有场地通则。饮品避开易踢翻路径，垃圾集中投放，洒落及时通知保洁处理。

摄影机位不挡商户入口、观众通道和表演者路线，说明拍摄范围和不愿出镜的沟通方式；高层拍摄、逆光/HDR/曝光仅按真实光线、器材和场地方许可处理，不复用旧日太阳角度或保证画质。

## 环节转换、异常与撤场

路演前清场并核对全员/道具，收到总控信号播放；路演后完成退场、撤道具和地面检查，再开放随舞。中场复核兼组准备、人员到齐和最新音频，不只按表上时间自动播放。

音频故障、团队迟到、拥挤、湿滑、天气或人员不适时由指定总控和商场接口按预案暂停，记录事实、受影响段落和恢复条件；医疗处置交现场适当人员，不由主持臆断。恢复前明确哪曲/哪段、成员就位与实际剩余时间。

按场地截止停止音乐并引导散场，检查人员/失物、设备/道具、垃圾、临时物料和线路，完成获准撤除与场地恢复；与商场按书面约定验收留证，记录未完成项及责任人。结算依据真实交付，不用“活动结束”替代验收/付款完成证据。
