# 路演时段与兼组检查

读取正式节目、成员、实测音频和场地窗口。通过但未编排、候补、缺材料分别列出；候补未转正式不得占正式时长。公开序号不替代稳定节目ID。

先落实固定开始时间、锁定组序、到场/离场、道具与成员准备等硬条件，再考虑风格交替或团队偏好。固定第几组并不代表固定几点。未知准备时间不能当零，草案假设需标注，定稿由负责人确认。

每项占用=主持介绍+入场就位+实测音乐+退场撤道具−已确认的介绍/入场重叠。重叠不能超过两项较短者；未确认不自行扣除。空档说明用途，汇总与子节目避免双计。

逐成员按出演顺序检查：下一节目候场开始 ≥ 上一节目退场完成 + 下一节目前所需准备；还要满足到场及最晚离场约束。不是“隔一组就够”，也不能用音乐起点相减。

排不下时提出调整未锁定时段、增加转换、改变路演段或减少节目等方案，等相应决定，不删成员、不缩短已确认音频。任何交换/移动都重查所有受影响成员、固定条件与总时长。

使用 [编排表](../assets/templates/roadshow-arrangement.csv)，记录正式与未排节目、冲突原因、候场、音频版本、确认人及时间。迟到补位前先查材料、全员、道具和剩余时间。最终同步公开组序、主持、播放及催场资料。
